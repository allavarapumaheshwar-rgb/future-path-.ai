# FuturePath AI (06)

Create a complete modern AI-powered Career Guidance Platform called "FuturePath AI".

The platform should help students from Class 10, Intermediate, Degree, and Graduates discover the best educational streams, career opportunities, colleges, scholarships, skills, government jobs, entrepreneurship opportunities, and future-ready careers.

Design a premium EdTech-style website with a professional blue and white theme, modern UI/UX, responsive layout, smooth animations, attractive icons, cards, gradients, and mobile-friendly design. The website should look like a combination of a career counseling platform, educational guidance portal, and student success ecosystem.
